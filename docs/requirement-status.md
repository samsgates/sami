## Production acceptance and research limits

The supported release is a bounded native runtime and experimental lab, rather than a general intelligence engine. Customer dataset acquisition, validated risk/coverage, market uniqueness, integration economics, independent security, Docker/Kubernetes scans, load/HA and genuine comparative model benchmarks are acceptance work that source generation cannot establish. The accompanying code never enables physical equipment control or financial payouts.

Schema migration currently uses additive initialization and versioned immutable records. Keep prior packs for replay and start new runs when definitions change. Test backup/restore on an isolated installation before an upgrade; automatic arbitrary data migrations, live artifact canaries and signing-key history are pending.
