# Evaluation and research

Run `cargo test --workspace --locked` for bounded native, runtime and research contracts. The tests cover real durable end state, source/claim correction, tenant/ACL isolation, deleted replay content, serial/unit/time conflicts, stable-key execution and backup restore with newer tombstones. PostgreSQL is a separate explicit integration test with an isolated empty test database. These fixtures are generated; they do not meet the PRD's customer sample-size gates.

`cargo run --locked -p sami-research --example benchmark` runs five actual native baselines on the generated binary-hours exercise. It splits train, inner validation, calibration and locked transfer cases by independent source family/time, freezes the chosen program before transfer evaluation, and exposes test errors. The explicit 2,000-hour rule has authored domain knowledge; the induced rule learns only from its example labels and can miss boundary cases. The comparison does not test a complete warranty policy, customer outcomes, frontier models, causal transfer or large-scale latency. Actual run output is in `docs/verification/generated-benchmark.json`.

The lab supplies logistic/Platt/isotonic calibration, Brier/log loss/bin ECE, selective risk/coverage, Wilson/binomial-style uncertainty, explicit split-overlap checks, PSI/KS-style drift measures, and bounded conformal prediction. Follow artifact compatibility and split semantics in the examples/tests. Native operational decisions return `probabilities:null` and deterministic rule checks; a toy lab artifact is not automatically connected to live serving.

Safe bandits choose only among declared low-risk strategies. Record eligibility, exact propensity, delayed outcomes, duplicate/stale-policy checks and off-policy support. They cannot explore source authority, payouts, safety or permissions. Feedback remains quarantined; promotion records shadow candidates without replacing live packs. Wider canary deployment and statistically justified promotion remain reviewed release work.

The pure DSL supports typed comparisons, conversion, conditionals, bounded map/filter/join/projection, temporal filtering and registered subprocedures. Enumerative induction penalizes complexity and uses inner validation; it rejects transfer-set access for selection. Output is a candidate, with its assumptions and counterexamples, never executable unrestricted code. Sequence indexes preserve document boundaries and checksums. PPMI, truncated LSA, signatures and similarity provide bounded semantic experiments rather than a general pretrained language model.

`causal.analyze` supplies a narrow randomized/backdoor-adjustment mean-difference estimator with declared assumptions, overlap checks, approximate uncertainty and a sensitivity-bias interval. It reports an assumption-based estimate; it cannot verify exchangeability, identify arbitrary causal graphs, infer causality from word frequency or authorize an experiment.

Before a paid deployment obtain consented/de-identified real cases, lock the intended equipment/time/source population, prevent answer leakage, independently review critical outcomes and source applicability, report human-review burden, and test actual destination integrations and infrastructure. Complete the PRD's accepted-case/severe-error, cohort, performance, security, restore and economic gates. The source implements measurement primitives; no measurement target is a passed result merely because its code exists.
